## Descripción

Este proyecto es una *simulación de tráfico* en un entorno poblado por *56 robots, programada en **Java* y utilizando la librería *Karel J. Robot* para la simulación y visualización.

---

## Ejecución del programa

### Opción 1 – Usando los archivos .bat

1. *Compilar*
   Ejecute el archivo:

   
   compilar.bat
   

2. *Ejecutar*
   Ejecute el archivo:

   
   run.bat
   

---

### Opción 2 – Usando comandos en consola (Linux)

1. *Compilar el proyecto manualmente*

   
   javac -d . -cp ".:KarelJRobot.jar" Main.java
   

2. *Ejecutar el proyecto*

   
   java -cp ".:KarelJRobot.jar" Main
